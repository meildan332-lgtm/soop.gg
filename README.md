# SOOP 엠블럼 랭킹

SOOP 스트리머의 현재 엠블럼 등급, 누적 유저와 다음 등급까지의 진행 상황을 검색하고 비교하는 비공식 팬 정보 사이트입니다.

## 실행

```bash
npm install
npm run dev
```

현재 데이터는 UI 검증용 샘플입니다. `src/data.js`를 실제 공개 데이터 수집기 또는 DB API로 교체할 수 있도록 등급 계산(`src/tiers.js`)과 화면 코드를 분리했습니다.

## 주요 기능

- 닉네임·SOOP ID 실시간 검색
- 카테고리·등급 복합 필터
- 누적 유저·승급 임박·닉네임 정렬
- 누적 유저 기반 등급 및 구간 진행률 자동 계산
- 스트리머 상세 페이지
- 데스크톱 테이블 / 모바일 카드 반응형 UI
